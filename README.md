## things i work with

`Python` · `GTK4 / PyGObject` · `Cairo` · `Linux` · `Fedora` · `Git` · `Astro` · `JavaScript`

I care more about understanding the system than collecting technologies. Most of what I know came from building something, breaking it, tracing why it broke, and writing down the lesson afterward.

```text
build
→ break something
→ inspect the evidence
→ fix the smallest responsible thing
→ learn why
→ write it down
```
