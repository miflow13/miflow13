## Featured projects

### 🌱 [Mochi](https://github.com/miflow13/mochi-desktop)

A lightweight pixel-art desktop companion for Linux that idles, reacts, wanders, sleeps, and hangs out while you work.

Mochi is where I'm exploring **state-driven behavior, animation systems, GTK desktop UI, interaction design, testing, and Wayland/XWayland constraints** while trying to make a tiny character actually feel alive.

**Current:** `0.2.0-alpha` · active development

### ⌨️ [KeyFlip](https://github.com/miflow13/KeyFlip)

A GNOME utility for safely enabling and disabling a laptop's built-in keyboard while keeping external keyboards available.

It includes **GTK4 controls, a GNOME Shell extension, automatic keyboard detection, keyboard shortcuts, safety checks, Cleaning Mode, and Fedora COPR packaging**.

**Current:** `0.2.0-beta` · available through Fedora COPR
